1️⃣ First: what problem does Bridge solve?
    👉 When one thing varies in TWO dimensions and inheritance explodes.
    Example:
        Shapes → Circle, Square
        Colors → Red, Blue

2️⃣ The core idea
    Bridge separates “what an object is” from “how it is implemented.”
    Abstraction → what
    Implementor → how

    They are connected by composition (has-a).

3️⃣ Diagram
    Abstraction ─── has ───► Implementor
     ↑                      ↑
    RefinedAbstraction   ConcreteImplementor


abstract class Shape {
    protected Color color;   // 🔥 bridge
}

Shape and Color vary independently
No class explosion
New color? → no change in shapes
New shape? → no change in colors

🔥 THIS is Bridge.
